# История изменений

[English](CHANGELOG.md) · [Русский](CHANGELOG.ru.md) · [简体中文](CHANGELOG.zh-CN.md)

## 1.2.2

- Переработана навигация по канвасу: прокрутка двумя осями теперь по умолчанию панорамирует канвас, а щипок и `Cmd/Ctrl+колесо` масштабируют от точки фокуса; прежний режим «прокрутка — масштаб» остался в настройках с сохранением направления и чувствительности.
- Логическое владение вводом для виджетов: виджет захватывает колесо после явного клика или настраиваемой задержки наведения, удерживает фокус до клика вне виджетов, режимы захвата `Off / On / Key`; отдельный удерживаемый биндинг временно захватывает всю навигацию канваса, включая перетаскивание.
- Сохранена непрерывность жестов через поверхности нативного Браузера: владение «страница/канвас» фиксируется на 250 мс неактивности колеса, щипок и `Cmd/Ctrl+колесо` всегда масштабируют канвас, а сфокусированная страница Браузера продолжает прокручиваться нативно при выключенном захвате.

## 1.2.1

- Canvas-приложения плагинов теперь открываются и повторно фокусируются в нативном масштабе `1.0`, без размытия от дробного scale; прозрачный фон iframe также убирает светлую полосу вокруг скруглённого окна плагина.
- Semantic summaries терминала и браузера теперь заранее резервируют ширину под counter-scale и сохраняют содержимое по центру, поэтому иконки и текст не обрезаются при сильном отдалении canvas.

## 1.2.0

- Нативный window chrome на macOS: скрытый title bar с traffic-light кнопками, компактный brand bar и корректное поведение в native fullscreen; на Linux и Windows остаётся прежняя кастомная рамка.
- Секреты плагинов с OS-шифрованием через Electron safeStorage (fail-closed, если системный keyring недоступен): проверка permission на каждый вызов, квоты, события изменений и очистка при удалении плагина.
- Плагины могут добавлять собственный пункт настроек (открывается в sandboxed frame), задавать минимальные размеры canvas и открывать второй canvas того же плагина рядом с текущим.
- HOME-виджеты плагинов показываются рядом с встроенными в Appearance → HOME composition и добавляются/убираются как родные — это закрывает известную недоработку 1.1.0; в Settings → Plugins остались только установка и удаление.
- Опциональные модули плагинов: выбор при установке, проверка SHA-256 и точного размера каждого файла, атомарная переконфигурация с rollback, а module-derived permissions единообразно применяются к SDK-авторизации и CSP ресурсов плагина.
- События изменения storage плагина теперь рассылаются из main-процесса: canvases, HOME-виджеты и отдельные окна одного плагина видят записи друг друга.
- Загрузки плагинов усилены: редиректы ограничены хостами `api.github.com` и `raw.githubusercontent.com`, загрузка модулей использует retry/backoff из 1.1.0.
- Задокументирована trust model опциональных модулей: целостность файлов привязана к манифесту плагина, получаемому с GitHub по TLS без отдельной подписи.

Известная недоработка: установленные плагины пока нельзя обновить на месте — для получения новой версии удалите плагин и установите заново. Действие обновления запланировано.

## 1.1.0

- Native-страницы браузера масштабируются под zoom канваса через Chromium zoom factor (ограничен 0.5–3): содержимое браузера следует масштабу канваса при любом zoom.
- Viewport bounds браузера сообщаются синхронно, а native view остаётся видимым во время панорамирования, перетаскивания и resize канваса; это исправляет проблему 1.0.2, когда native browser view мог перекрыть не-maximized окно и заблокировать управление канвасом.
- Web contents вкладки браузера получают фокус по pointer-down на канвасе — ввод попадает на страницу без лишнего клика.
- В Settings добавлен переключатель индикаторов присутствия агентов в браузере (по умолчанию включён): badges/cursors больше не появляются при аутентификации, курсоры рисуются точками без имён и показываются только для агентов, реально работавших с браузером.
- Загрузка плагинов с GitHub повторяется до трёх раз с backoff при временных сбоях (таймауты, ошибки соединения, HTTP 408/429/5xx, оборванные потоки).
- Добавлен перезапуск терминальной сессии: кнопка restart на завершённых карточках и shortcut `Ctrl+D`; PageUp/PageDown листают scrollback в обычном буфере, а курсор терминала стал блоком.
- Wheel zoom поверх приложений теперь включён по умолчанию.
- Документация синхронизирована на английском, русском и упрощённом китайском.

Известная недоработка: кастомизация HOME-раскладки для внешних плагинов не завершена — плитки плагинов пока нельзя размещать и перемещать в редакторе раскладки HOME. Задача открыта, вклад сообщества приветствуется.

## 1.0.2

- Встроенный браузер открыт из HOME как перемещаемое и изменяемое по размеру canvas-приложение с доверенными tabs/navigation, downloads, site dialogs, безопасным восстановлением вкладок, очисткой browser data, semantic summaries и стабильной native-view geometry во время движения камеры/карточки.
- Для сессий Claude Code, Codex и Kimi, запущенных через CanvasTTY, добавлена scoped browser automation через встроенный stdio MCP helper и аутентифицированный Unix socket текущего пользователя или защищённый Windows named pipe; TCP listener, remote-debugging port, произвольный JavaScript, cookie/storage API и raw CDP не открываются.
- Добавлены badges/cursors подключённых агентов, изоляция activity по агентам, element refs с document revision, FIFO mutations по вкладкам, request deduplication, ограниченные concurrency/rate limits/timeouts, работа с dialogs/downloads и очищенные screenshots с fail-closed при невозможности надёжно закрыть чувствительные области.
- Добавлен постоянный очищенный hash-chain аудит браузера в Electron `userData/browser/audit`: ротация при 100 МБ, retention ротированных файлов 30 дней, integrity checks и fail-closed agent mutations, если обязательный pre-action audit нельзя записать.
- Карточка браузера интегрирована с terminal-equivalent выбором на канвасе, click/hover focus, снятием выбора по пустому канвасу, window actions, wheel zoom поверх приложений и стабильной renderer surface во время перемещения native view.
- Windows agent transport усилен встроенным native named-pipe host, доступным только точному SID текущего пользователя; release pipeline дополнен реальными Electron/provider smoke tests.
- Исправлен secret audit репозитория для linked Git worktree: имена repository metadata игнорируются до определения типа entry, при этом personal path в публикуемых файлах по-прежнему обнаруживается.
- Документация браузера, безопасности, локальных данных, audit log и релиза синхронизирована на английском, русском и упрощённом китайском.

Известная проблема: если главное окно CanvasTTY изначально открылось не maximized, запуск Browser может растянуть native browser view на всё окно и сделать управление канвасом недоступным. В этом prerelease запускайте CanvasTTY maximized до открытия Browser; исправление запланировано на следующий patch.

## 1.0.1

- Добавлен перенос строки в терминале через `Shift+Enter` без отправки текущего промпта.
- Исправлены выбор терминала и клавиатурный фокус: ввод сразу идёт в xterm выбранной живой карточки, а нажатие по пустому канвасу снимает выбор и рамку.
- Добавлен опциональный автофокус при наведении с задержками входа и выхода: медленно (`500ms`), обычно (`250ms`) и быстро (`80ms`). Программный hover focus больше не отправляет focus-report sequences в TUI агента и не перебрасывает его в начало истории.
- Добавлены независимые настройки направления колеса для терминала и канваса. По умолчанию колесо вниз прокручивает терминал вниз, а зум канваса сохраняет прежнее направление.
- Вывод PTY объединяется в renderer-обновления по 16 мс, а повторное копирование строки scrollback заменено ограниченным chunk-буфером. Это устраняет мигание при больших объёмах вывода и сокращает сбросы истории.
- Очереди записи настроек, реестра плагинов и разрешений медиакаталогов теперь восстанавливаются после временных ошибок файловой системы, а метаданные клиентов провайдеров соответствуют версии приложения в пакете.
- Добавлено полное руководство по runtime-плагинам на упрощённом китайском, синхронизированы инструкции по терминалу на трёх языках и описаны локальные данные плагинов, медиапапок и браузера.
- Добавлена лицензия MIT и локализованы Security, Changelog, Architecture и UI Contract.

## 1.0.0

- Добавлена лёгкая локальная стартовая страница, которая появляется до инициализации настроек, плагинов, медиа и IPC; ошибки bootstrap теперь показываются на видимой странице с fallback на нативный диалог вместо пустого окна.
- Добавлена блокировка второго экземпляра Electron: повторный запуск восстанавливает и фокусирует существующее окно.
- Координаты указателя терминала преобразуются из CSS-трансформации канваса обратно в координаты layout xterm, поэтому выделение текста, mouse reporting в vim/tmux и прокрутка работают при любом масштабе.
- Переработаны сочетания буфера обмена терминала: копирование через `Ctrl+C` при выделении, `Ctrl+Shift+C` или `Cmd+C`; вставка через `Ctrl+Shift+V`, `Cmd+V` или `Shift+Insert` с использованием `Terminal.paste`. Сочетания привязаны к физическим клавишам и работают с нелатинскими раскладками.
- Добавлен smoke harness упакованного приложения (`CANVASTTY_SMOKE_TEST=1` печатает `CANVASTTY_SMOKE_READY` после первого кадра) и подключён к Linux release pipeline под `xvfb-run` с FUSE2.

## 0.9.99 — публичное превью

- Добавлен permissioned registry runtime-плагинов для готовых статических GitHub-репозиториев.
- Добавлены manifest v1 contributions: sandboxed HOME widgets, перемещаемые canvas apps и отдельные окна CanvasTTY.
- Добавлены preview и проверка permissions перед установкой, включение/выключение/uninstall, изолированное storage, CSP-ограниченные assets и общий host SDK.
- Добавлены постоянные разрешения на выбранные пользователем музыкальные каталоги, seekable локальные аудиопотоки и ограниченные API чтения/записи плейлистов.
- Добавлена sandboxed core-заготовка встроенного браузера с вкладками, навигацией, постоянным изолированным профилем и геометрией карточки; из HOME она намеренно не запускается.
- Фиксированная композиция HOME заменена на просторную сохраняемую сетку `16 × 12` с визуальным редактором перемещения и размера при сохранении утверждённой раскладки.
- Добавлены resize окон и HOME widgets за любую грань, видимые только при редактировании границы HOME, временное размещение за границей, проверка перед Save и изоляция edit mode от остальных окон канваса.
- Добавлена документация архитектуры/runtime-плагинов и полный пример пакета Studio Kit.

## 0.9.2 — публичное превью

## 0.9.1 — публичное превью

- Восстановлен поиск CLI провайдеров при графическом запуске AppImage: desktop `PATH` дополняется существующими пользовательскими каталогами, включая `~/.kimi-code/bin`.
- Поздние terminal input/resize events больше не роняют main-процесс Electron при гонке с завершением PTY (`EBADFD`).

## 0.9.0 — публичное превью

- Исправлено непоявление главного окна, когда renderer успевал отрисоваться до завершения `loadURL`; listener `ready-to-show` теперь устанавливается заранее.
- Добавлено RTS-движение канваса от краёв, выключенное по умолчанию и останавливающееся над интерактивными поверхностями.
- В Settings добавлены переключатель/скорость движения от краёв и чувствительность зума колесом.
- Settings разделены на General, Appearance и Controls.
- Добавлены режимы Off, Single click и Double click для фокуса/приближения терминала; автоматический click focus выключен по умолчанию.
- Добавлены переназначаемые application shortcuts: `Home` для домашней зоны и `F2` для inline-переименования окна, а также скрываемая живая подсказка.
- Состояние PTY и scrollback сохраняются при смене палитры, узора, настроек и собственного заголовка окна.
- Улучшены clipboard shortcuts терминала, resize за края, semantic zoom и многоязычная документация.

## 0.8.0 — публичное превью

- Пространственный канвас для живых локальных PTY и CLI-сессий AI-агентов.
- Фиксированная Home-зона с launcher, sessions, clock, media и лимитами провайдеров из реальных источников.
- Перемещаемые и изменяемые по размеру terminal cards с snapping и semantic zoom navigation.
- Изоляция процессов Electron с типизированным IPC из белого списка и локальными настройками.
- Точки входа и документация на английском, русском и упрощённом китайском.
- Воспроизводимая упаковка Linux, Windows и macOS через GitHub Actions.
- Аудит секретов репозитория и строгий allowlist содержимого пакета.

Ограничения превью: runtime widget plugins ещё не реализованы; Windows и macOS требуют более широкой проверки на реальных устройствах; release packages не подписаны и не notarized.
